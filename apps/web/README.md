# Financial Pods web bootstrap

This directory contains the Sprint 00 Next.js application skeleton. It exposes
an accessible placeholder at `/` and a container-compatible health endpoint at
`/health`. Product functionality is intentionally absent.

## Local commands

```text
pnpm install --frozen-lockfile
pnpm dev
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm e2e
```

The development server listens on `http://localhost:3000`. Playwright starts
the server automatically when one is not already running.
