# Reference Artifacts

This directory contains the finalized source artifacts used as immutable research, specification, engineering, growth, presentation, prototype, and provenance inputs for Financial Pods.

## Handling rules

- Do not edit, rename, replace, or regenerate finalized DOCX, PDF, PPTX, HTML, or ZIP files in place.
- Preserve original filenames and directory categories.
- Verify canonical copies against the sizes and SHA-256 checksums in `../../ARTIFACT_CATALOG.md`.
- Treat the extracted developer-agent starter pack as reference guidance; live root documents and the active sprint remain authoritative.
- Add any newly received finalized artifact to the catalog before using it.

## Current categories

- `research/` — master strategy, research, and implementation blueprint
- `specifications/` — finalized V1 functional and technical specification
- `engineering/` — engineering, deployment, coding, and assurance references
- `growth/` — finalized content growth and publishing strategy
- `deck/` — strategy and implementation presentation
- `prototype/` — Golden Lesson UI/experience reference
- `developer-agent-starter/` — extracted starter guidance preserved by relative path
- `source-packages/` — immutable original ZIP packages

The catalogued artifact set was organized and checksum-verified on 2026-08-16. These artifacts provide evidence and requirements but do not independently authorize implementation outside the active sprint.
