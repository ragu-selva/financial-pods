# Regulatory Content Authoring Skill

Use when adding or updating a regulatory lesson.
1. Identify primary official source and status.
2. Create/update canonical concept and jurisdiction mapping.
3. Capture exact citations and effective/version metadata.
4. Draft lesson assets from structured data.
5. Add deterministic calculation fixtures and boundary tests.
6. Add active-learning and viva rubric.
7. Run source/citation and AI eval checks.
8. Route for SME review; never publish automatically.
