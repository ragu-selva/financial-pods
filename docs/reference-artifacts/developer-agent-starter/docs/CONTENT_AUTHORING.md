# Content Authoring Standard

Every lesson must define:
- learning objectives;
- prerequisites;
- canonical concepts;
- jurisdiction/rule mappings;
- synthetic examples;
- deterministic tools;
- common misconceptions;
- active-learning checkpoints;
- practice templates;
- viva rubric;
- citations;
- language glossary;
- SME reviewers;
- version/effective dates.

The AI may draft content, examples and questions. Human SMEs approve authoritative interpretation, calculation expectations and jurisdiction-specific content before publication.
