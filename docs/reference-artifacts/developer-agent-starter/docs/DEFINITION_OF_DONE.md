# Definition of Done

A feature is done only when:
- acceptance criteria are met;
- accessible responsive UI is complete;
- code is typed/linted/formatted;
- unit/integration/e2e tests pass;
- AI evals pass where relevant;
- telemetry exists;
- privacy/security review is complete;
- error/empty/loading states exist;
- documentation is updated;
- migration/rollback is defined if data changed;
- feature flag/kill switch exists for risky AI/media behavior;
- cost impact is measured for provider-backed features;
- product owner/SME acceptance is recorded where content correctness is involved.
