# Localization

## Launch
English + Modern Standard Arabic, with an optional Arabic explanation mode that preserves common English banking acronyms/terms.

## Architecture
- Concept and rule IDs are language-neutral.
- Localized lesson strings, captions, transcripts and voice assets are versioned independently.
- Original regulatory source language is retained.
- Glossary entries are centrally managed and reused by scripts, tutor prompts and UI.
- RTL support is tested in the design system and e2e suite.

## Quality gates
Machine localization must receive financial/regulatory linguistic review before publication for authoritative learning content.
