# Implementation Roadmap

## Sprint 0 — Architecture lock
Contracts, repo, CI, local environment, observability skeleton, ADRs.

## Sprint 1 — Content/domain core
Rule/concept/lesson schemas, Golden Lesson seed, content review state machine.

## Sprint 2 — Learner experience
Dashboard, lesson player, semantic timeline, progress events.

## Sprint 3 — Deterministic lab
Corporate exposure calculator and jurisdiction rule adapters.

## Sprint 4 — Grounded text tutor
Retrieval, citations, tool calling, session context.

## Sprint 5 — Active learning/mastery
Checkpoints, events, mastery derivation, misconception tracking.

## Sprint 6 — Voice
Realtime interruption, transcript, voice tutor, cost/latency telemetry.

## Sprint 7 — Arabic
RTL, glossary, localized content, Arabic evals and voice QA.

## Sprint 8 — Viva/practice
Practice generation, rubrics, voice viva, results dashboard.

## Sprint 9 — Content factory
Admin review, media pipeline, semantic timeline generation.

## Sprint 10 — Practitioner pilot
10–20 practitioners, learning/quality/pay-intent feedback, architecture review.
