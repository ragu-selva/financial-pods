# Incident Response

## Severity examples
- SEV1: security breach, widespread inability to access lessons, materially wrong authoritative calculation/regulatory content presented to many learners.
- SEV2: major feature unavailable, voice/tutor widespread failure, incorrect localized content with material learning impact.
- SEV3: isolated defects or degraded non-critical features.

## Regulatory-content incident
Immediately unpublish/flag affected lesson version, preserve audit evidence, identify affected learners, correct through a new immutable version, rerun tests/evals, and communicate correction where warranted.
