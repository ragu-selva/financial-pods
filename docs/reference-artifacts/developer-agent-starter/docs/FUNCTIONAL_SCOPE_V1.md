# Functional Scope — V1 Golden Lesson

## In scope
- User signup/login and learner profile.
- Course catalog with Basel Pod.
- Golden Lesson 001 in English and Arabic.
- Chaptered video player with semantic timeline.
- Pause-and-ask text tutor.
- Realtime voice tutor with interruption/barge-in behavior.
- Official source panel with jurisdiction/status/version.
- Interactive corporate exposure calculator.
- BCBS/U.S./SAMA/CBUAE comparison view.
- Active-learning checkpoints.
- Practice-case generation constrained by reviewed templates.
- Voice viva and rubric-based scoring.
- Concept mastery dashboard.
- Admin content workflow: draft -> SME review -> approved -> published -> superseded.
- AI/provider usage and cost telemetry.

## Explicitly out of scope for V1
- Full Basel curriculum.
- Enterprise SSO and SCIM (design-compatible, phase 2).
- Native mobile apps.
- Live avatar as a mandatory runtime dependency.
- Large real-bank portfolio processing.
- Spark/Kubernetes.
- General-purpose user-generated courses.
