## Product principle
Financial Pods is not an AI chatbot wrapped around videos. The runtime teaching system must combine reviewed course content, official regulatory sources, deterministic finance tools, learner mastery, and contextual chat/voice tutoring.

## V1 scope
Golden Lesson 001: Corporate Exposure — From Bank Loan to Regulatory Capital. Initial regulatory contexts: BCBS baseline, U.S., SAMA, and CBUAE. Initial languages: English and Arabic.
